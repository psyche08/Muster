# Repository Instructions

Follow [AGENTS.md](AGENTS.md) for repository architecture, development,
validation, commit, and security requirements.

## Language

- Write pull request titles and descriptions in English.
- Write repository documentation in English. When adding or updating a
  document, keep its prose, headings, captions, and examples in English.
- Preserve code identifiers, commands, paths, protocol literals, and quoted
  source material when translating would change their meaning.
- These rules apply to repository artifacts; respond to users in their
  preferred language.
